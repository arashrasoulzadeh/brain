# Plugin template

## Developer

Use the template to learn the `sdk.context`, `sdk.pipeline` and `host.model` helpers. The example route returns the host-bound project and emits its declared event. Model routes demonstrate create/read/list/update/delete and publish transitions. Copy the pattern into a new manifest with unique IDs, capabilities, source/import declarations and tests.

## Administrator

The template is a registered example, not a production feature. Install only in a fixture project. Grant the manifest capabilities and verify model state transitions, project isolation, observation grants and denial of undeclared operations before promoting a new plugin.
