Administrator guide

Current capabilities

  • Project status resolution
  • Plugin registration with host API compatibility
  • Per-project plugin installation
  • Capability grants
  • Grant-gated enablement
  • Project-scoped authorization
  • Separate runtime and migration credentials

Current limitations

The dashboard, operator MFA, recovery, worker supervision, external workers, and audit storage are not implemented yet. The current HTTP host is not production-ready.

Operational policy

  • Keep development and production project IDs separate.
  • Use migration credentials only for schema changes.
  • Keep runtime credentials unable to run DDL.
  • Use Docker/Compose only for explicit integration or release checks.
  • Record the commit and test result for every roadmap item.
