Developer guide

Workflow

  1. Read AGENTS.md and the relevant phase guide.
  2. Select the first unchecked roadmap item.
  3. Write one failing test.
  4. Implement the smallest passing change.
  5. Run formatting and GOCACHE=/tmp/brain-go-cache go test ./....
  6. Update the verified checkbox.
  7. Commit and push before the next item.

Local development

Do not run Docker during normal development. Use in-process tests and isolated local settings. Use PostgreSQL integration tests for roles, row-level security, migrations, locks, and PostgreSQL-specific transactions.

Package boundaries

  • cmd/brain: startup and wiring
  • internal/app: HTTP routing
  • internal/config: configuration
  • internal/db: database ownership and readiness
  • internal/migrate: migrations
  • internal/project: project isolation
  • internal/plugin: plugin registration and authorization

Security

Never trust project IDs, grants, membership, or permissions supplied by clients. Recheck lifecycle, grants, versions, and idempotency at commit time. Keep secrets out of logs and tests.
