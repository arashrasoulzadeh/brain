# Database

Route: `/database`

Runs project-scoped table operations through the Tables plugin. Requires Tables to be ready and enabled. Uses the shared admin sidebar.

This is the Tables manifest alias, not an SQL console. Select an authorized table name from inventory, query schema or read rows, and confirm a JSON row write. The current adapter persists SQLite row snapshots. Do not enter arbitrary SQL or assume the displayed rows are a PostgreSQL schema.

See the [admin route index](README.md) and [HTTP API](../http-api.md).
