# Functions

Route: `/{project}/ui/functions`

Lists authorized drafts for the active project. Requires the Functions installation to be enabled and ready. The list displays name, version, visibility and timestamp. Select a row for the editor or choose Create function.

Access Management filters drafts by the exact operator and function name under functions.inspect. A listed draft is not proof that its public endpoint is usable. Check publication, declared method and functions.call policy separately.

See [create function](function-new.md), [function detail](function-detail.md) and [function runtime](../functions-runtime.md).

Search by function name, filter by configured visibility and publication state, and manually refresh the project function catalog. Publication refers to the current host record, not a deployment history.
